# 🍽️ 오늘 뭐 먹지?

지금 기분이나 상황을 자유롭게 적으면 메뉴를 골라 주는 음식 추천 사이트예요.
**AI도 API 키도 쓰지 않아요.** 입력한 글에서 키워드를 찾아 미리 정리해 둔 83가지 메뉴 중에서 고르는 방식이에요.

🔗 배포 주소: https://what-to-eat-sigma-nine.vercel.app

## 기능
- 자유 입력 → 키워드 분석 → 가중치 랜덤 추천 (맞을수록 자주 나오고, 가끔 깜짝 추천)
- "매운 거 **말고**", "삼겹살 **빼고**" 같은 부정 표현 이해
- 가격대 선택 (1만원 이하 / 1~2만원 / 2만원 이상)
- 룰렛 연출, 효과음, 잔잔한 배경음악 (소리 파일 없이 브라우저가 직접 만들어요)
- 근처 맛집 찾기(네이버 지도), 결과 공유하기

## 파일 구성
| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면의 뼈대 |
| `style.css` | 디자인 (맨 위 `:root`의 색만 바꿔도 분위기가 바뀌어요) |
| `script.js` | 모든 동작 (메뉴 목록, 추천 로직, 소리) |
| `tests.html` | 자동 테스트 페이지 |
| `og-image.png` | 링크를 공유할 때 보이는 썸네일 |

## 직접 고쳐 보기
`script.js` 안에서 고쳐요.

- **메뉴 추가**: `menus` 목록에 한 줄 추가
  ```js
  m("🍱 도시락", "간단하게 먹기 좋아요.", "한식 밥 간단 빠른 혼자"),
  ```
  그리고 `PRICE`에 가격대를 적어요: `"도시락": 1,` (1 = 1만원 이하, 2 = 1~2만원, 3 = 2만원 이상)
- **알아듣는 말 늘리기**: `synonyms`에 `[["입맛 없", "식욕 없"], ["담백"]]`처럼 추가
- **다른 이름으로 불러도 찾게 하기**: `ALIASES`에 `"돈카츠": ["돈가스"]`처럼 추가

## 실행과 테스트
- **실행**: `index.html`을 더블클릭하면 브라우저에서 바로 열려요. 설치할 게 없어요.
- **테스트**: 배포된 주소 뒤에 `/tests.html`을 붙여서 열면 돼요. (예: `.../tests.html`)
